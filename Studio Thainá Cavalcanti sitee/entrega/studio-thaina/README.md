# Studio Thainá Cavalcanti · landing page

Site estático (HTML + CSS + JS). Abra `index.html` ou publique a pasta inteira (GitHub Pages, Netlify, Vercel).

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `studio-thaina`) e envie o conteúdo desta pasta para a branch `main`.
2. Settings → Pages → Source: `main` / root.

## Pendências antes de ir ao ar
- Horário de funcionamento (seção Visita)
- FAQ: dor/anestésico, tempo de cada atendimento, gestantes e lactantes
- Cursos: valor, parcelas, data da próxima turma, duração
- Nome + serviço em cada depoimento de cliente
- Foto da fachada/recepção do studio (vai ao lado do mapa)
- Vídeos: cortar em 10 a 15 s e comprimir para 2 a 3 MB cada
